## **Customer Churn Analysis**

#### **Overview**

A data analytics project that analyzes telecom customer churn to identify high-risk customer segments and understand the factors associated with customer retention.

#### **Objective**

- Analyze overall customer churn.
- Identify churn patterns across customer segments.
- Compare churn by contract, tenure, payment method, and services.
- Build a dashboard to communicate key findings.

#### **Tools Used**

- Python & Pandas
- MySQL / SQL
- Tableau
- Git & GitHub

#### **Dataset**

Telco Customer Churn dataset containing **7,043 customer records** with information about customer demographics, services, contracts, payments, charges, and churn.

#### **Workflow**

**Python → SQL → Tableau**

- Cleaned and prepared the dataset using Python.
- Performed business analysis using SQL.
- Built an interactive Tableau dashboard.

#### **Key Results**

- **Total Customers:** 7,043
- **Churned Customers:** 1,869
- **Churn Rate:** 26.54%
- **Average Monthly Charges:** ₹4,56,116.60
